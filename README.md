# PhoneDeck

O teu computador, num toque: transforma o telemóvel numa consola de botões para controlar música, volume, microfone, apps e atalhos do computador.

**Página e downloads:** https://strudall.github.io/phonedeck-app/

Grátis para macOS, Windows (beta) e Linux (beta). Sem instalar nada, sem contas, sem nuvem.

Os programas estão em [Releases](https://github.com/strudall/phonedeck-app/releases).
